## Why this package?

`@stackline/types-jest` is the Stackline-maintained distribution of `@types/jest@30.0.0`. It is an independent continuation of [@types/jest](https://github.com/DefinitelyTyped/DefinitelyTyped); original authors and licenses remain credited below.

## Installation

```bash
npm install --save-dev @stackline/types-jest
```

Preserve existing imports and plugin resolution with an npm alias:

```bash
npm install --save-dev @types/jest@npm:@stackline/types-jest
```

Use the original `@types/*` alias for automatic TypeScript type discovery and existing `compilerOptions.types` settings. A scoped-only installation does not automatically expose the original type-package name.
